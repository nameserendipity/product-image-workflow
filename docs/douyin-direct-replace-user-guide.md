# 抖音直链与批量产品替换使用说明

## 支持的任务

- 单个商品链接：淘宝、天猫、京东、抖音短链和抖音商品详情链接。
- 批量链接表格：按表格原顺序直接采集每个链接，可选择“仅采集”或“采集并生成”。
- 产品图批量替换：每个商品配对一张我方商品图和一个对标商品链接，采集后复用单链接“使用我方产品图”生成链路。
- Excel 图片搜同款：继续使用原有 1688 商品图搜同款流程，不受直链模式影响。

## 批量链接表格

在“链接生图 -> 批量商品链接”中选择“参考对标商品创作”。表格优先识别以下表头：

- `商品链接`
- `对标链接`
- `竞品链接`
- `URL`
- `淘宝链接`、`天猫链接`、`京东链接`、`抖音链接`

没有明确表头时，只读取第一列中的受支持链接。程序不会把未知链接降级为图片搜同款，也不会从第二款商品补采。

## 产品图批量替换表格

在“链接生图 -> 批量商品链接”中选择“产品图批量替换”。程序先按表头识别我方商品图和对标链接；没有表头时，只接受同一行恰好一张图片和一个受支持链接的情况。

可识别普通 Excel 嵌入图片和 WPS `DISPIMG` 单元格图片。出现多张候选图片、多个候选链接、缺图或缺链接时，该行会明确标记失败，不使用相邻行猜测。

可选 SKU 字段包括：

- SKU 名称
- 颜色
- 规格
- 价格
- SKU 参考图

用户提供的 SKU 数据标记为手工依据；没有可靠 SKU 数据时不会从标题或图片编造。

## 抖音采集说明

抖音短链会先解析成商品详情链接，再交给店透视下载资料包。资料包中的主图、详情图、SKU 图（如有）、商品参数和主视频会转换为统一采集清单。

当前实测部分抖音商品资料包不提供可验证的 SKU 名称、颜色、规格、价格或 SKU 图片。这种情况会记录为 `not_found`，不是程序采集成功后自动补造 SKU。需要生成准确 SKU 图时，请在产品图批量替换表格中提供 SKU 字段或 SKU 参考图。

## 运行与恢复

- “仅采集”不调用视觉分析、生图或 OSS，完成后可直接再次点击“采集并生成”复用素材。
- 停止后保留已下载素材、生成图片和检查点；再次运行会从未完成商品继续。
- 出现登录、验证码或平台风控时，采集器停止点击、滚动和刷新，等待人工处理。
- 空采集清单不会被标记为完成；明确记录某类素材不存在的清单可以保留真实缺失状态。

## OSS 与导出

- 采集原图只保存在本地，不上传 OSS。
- 生成成功的图片上传 OSS，并把公网 URL 写入每个商品的 Excel。
- 原视频已有公网 URL 时直接保留；只有本地 MP4 时上传 OSS 后写入视频 URL。
- 视频 OSS 上传失败时，商品任务标记为失败并保留已生成图片，修复配置后可以重试。
- 每个商品独立导出 Excel，包含总览、主图、详情图、SKU、商品参数、标题和视频；SKU 表保留生成图状态，但不再导出内部解析状态列。

OSS 配置方法见 [oss-local-setup.md](oss-local-setup.md)。

## 输出位置

批次结果保存在程序 `outputs/batches` 下。每个商品目录包含采集清单、生成目录、标题数据和独立 Excel；网页中的“打开文件夹”按钮可直接打开当前批次目录。
