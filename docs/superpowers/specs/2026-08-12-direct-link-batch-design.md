# 链接生图批量直采设计

## 目标

在现有“链接生图”页面增加“批量链接表格”入口。用户上传包含商品链接的 XLSX 后，程序严格按表格顺序直接采集每个指定商品，完成图片分析、生成、OSS 上传和结果导出。

该功能统一使用“参考对标商品”生成模式，不提供我方产品图替换模式。现有单链接页面仍保留“参考对标商品”和“使用我方产品图”两种模式。

## 功能边界

### 链接生图

包含两个入口：

1. 单个商品链接。
2. 批量链接表格。

两者共用同一套直接链接采集能力，不执行淘宝搜同款，不按销量搜索候选商品，也不从第二款商品补采素材。

### 表格生图

继续处理表格内嵌商品图，执行“商品图 -> 淘宝搜同款 -> 按销量选择 -> 素材不足时最多累计五款商品”的现有流程。本次不修改该流程。

## 输入识别

批量链接表格按以下规则读取：

1. 优先识别标题为“商品链接”“对标链接”或“URL”的列，标题匹配忽略大小写和首尾空格。
2. 没有上述标题时，仅当第一列包含可识别商品链接时，按第一列读取。
3. 空行跳过，但保留原始 Excel 行号用于进度和错误定位。
4. 同一表格允许混合淘宝、天猫和京东链接。
5. 短链接先解析最终地址，再校验平台和商品详情页结构。
6. 不支持的平台、无法解析的短链接、非商品详情页和失效链接标记为该行失败并继续下一行。
7. 不允许把未知链接降级为图片搜同款，也不允许程序根据单行内容切换批次类型。

上传完成后，界面显示总行数、有效链接数、无效链接数和不支持链接数。开始按钮只处理有效链接，无效行仍写入批次结果。

## 直接采集规则

每行只采集链接指定的商品：

1. 使用当前直接链接采集器打开商品详情页。
2. 使用店透视“下载全部图片（多文件）”获取并分类主图、SKU 图和详情图。
3. 采集商品标题、当前价格和商品参数。
4. 采集 SKU 颜色、规格、价格及可确认的 SKU 组合关系。
5. 获取商品原视频的可打开 URL，不把本地视频文件作为最终结果。
6. 保存结构化 manifest，供生成和 Excel 导出共同使用。

直接链接采集禁止搜索同款、禁止访问第二款候选商品、禁止混入其他商品素材。

若指定商品缺少某类素材：

- 已有类型继续生成。
- 缺少类型记录“无素材，已跳过”。
- 不使用其他类型图片伪装缺失类型。
- 不从其他商品补采。
- SKU 图缺失时仍可导出采集到的 SKU 参数，但不得虚构 SKU 图片与参数的对应关系。

## 生成规则

批量链接统一采用“参考对标商品”模式：

1. 第一张有效主图作为商品身份锚点。
2. 保留商品可确认的外观结构、材质和颜色，删除品牌、Logo、店铺名、水印和违规信息。
3. 主图、SKU 图和详情图复用单链接模式的分析、提示词和 `WorkflowRunner`。
4. 详情图复用多角度商品档案和视图规划逻辑。
5. 主图默认生成 10 张；以后若增加批次数量设置，则用户明确设置优先。
6. SKU 图生成数量限制为 3 至 8 张，但不能超过有效 SKU 素材数。
7. 详情图生成数量限制为 6 至 15 张；有效素材不足时使用商品档案规划可确认的多角度视图，不虚构未知结构。
8. 缺失的图片类型不进入生成队列。

生成结果上传 OSS，Excel 中写入可公网访问的生成图 URL。采集原图只保存在本地，不上传 OSS。

## 批处理编排

链接批处理按 Excel 原始行顺序逐个商品执行：

```text
读取并校验当前行链接
-> 直接采集指定商品
-> 校验可用素材和结构化数据
-> 分析并生成可用图片类型
-> 上传生成图片到 OSS
-> 导出当前商品 Excel
-> 写入断点进度
-> 继续下一行
```

链接批处理和图片搜同款批处理使用不同采集策略，但复用以下公共能力：

- 批次进度和 `batch-results.json` 断点格式。
- 停止、暂停和继续语义。
- `WorkflowRunner` 生图。
- OSS 上传。
- 单商品 Excel 导出数据模型。
- 批次事件和前端状态展示。

实现时不把直接链接逻辑塞进图片搜同款采集器。批处理编排器根据用户明确选择的入口调用对应策略：

- `ImageSearchCollector`：图片搜同款，可累计候选商品。
- `DirectLinkCollector`：指定链接直采，严格单商品。

## 暂停、失败与恢复

1. 遇到登录、验证码或平台风控时暂停整个批次，保留浏览器、当前行和已完成进度。
2. 用户完成验证后点击“继续批处理”，从当前未完成行继续。
3. 用户主动停止时保留浏览器，不自动重新采集。
4. 单个链接失效、下架、平台不支持或采集不到任何有效素材时，记录该行失败并继续下一行。
5. API 的 429、5xx、超时和临时网络错误按统一重试策略处理；重试耗尽后记录当前商品失败并继续。
6. 已完成行永久跳过；失败、停止和处理中断的行允许继续处理。
7. 更换输入表格后按新文件身份创建新批次，不继承旧表格的完成状态。

## 导出结果

每个有效商品导出一个独立 Excel，至少包含：

- 原始商品链接和平台。
- 商品标题、价格和商品参数。
- 主图、SKU 图、详情图的生成结果 URL。
- SKU 颜色、规格、价格和可确认的组合关系。
- 原视频 URL。
- 缺失素材类型和采集警告。
- 当前行处理状态与错误原因。

导出的图片数量只对应实际生成成功的图片，不混入全部采集原图。SKU 表不增加无对应关系的多余 SKU 图片行。

## 前端交互

“链接生图”页面增加单个与批量两个页签或分段控件：

- 单个链接：保留现有链接输入、模式选择和工作流区域。
- 批量链接：显示表格上传、识别统计、开始/继续、停止和打开批次文件夹。

批量链接入口固定显示“参考对标商品”，不显示我方产品图上传和模式切换控件。运行中显示当前 Excel 行号、平台、采集阶段、生成阶段和完成数量，不在工作流区域重复输出用户操作。

## 验收标准

1. 一张混合淘宝、天猫、京东及无效链接的表格可被稳定解析，并保持原行顺序。
2. 未知链接被明确标记，不会进入图片搜同款流程。
3. 每个有效链接只采集指定商品，不访问第二款候选商品。
4. manifest 包含图片、参数、SKU 颜色/规格/价格和视频 URL 的采集结果或明确状态。
5. 缺失某类图片时其他类型继续生成，缺失类型不补采、不伪造。
6. 批量生成与单链接参考模式使用相同的 `WorkflowRunner`、提示词和多角度详情逻辑。
7. 平台验证会暂停整批，继续后从当前行恢复；已完成行不重复。
8. 单个无效商品不会阻断后续商品。
9. 每个商品生成独立 Excel，生成图 URL 可公网访问，视频 URL 可直接打开。
10. 现有图片表格搜同款和单链接两种模式不发生行为回归。
